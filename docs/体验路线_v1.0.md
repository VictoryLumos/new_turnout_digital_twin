## 快速排错

| 症状 | 原因与处理 |
|---|---|
| python 不是内部或外部命令 | 用 开始体验.bat 的窗口执行；或命令换成 `D:\PY\python.exe` 开头 |
| can't open file … | 你不在项目目录。用 开始体验.bat 窗口（自动定位），或先 `cd C:\Users\1\Desktop\道岔数字孪生` |
| 网页 localhost:8000 打不开 | 第 4 步的黑窗口没开/被关了 → 重新双击 服务API演示.bat |
| 健康度一直不变 | 回放已结束（每工况只放一遍）→ 重新点工况名 |
| 8000/8765 端口被占 | 上一次演示的窗口没关 → 关掉旧的再双击 |
