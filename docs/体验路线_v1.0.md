# B 线成果体验路线 v1.0（15 分钟完整走一遍）

> 给自己/组长/队友的完整体验动线。前提：PostgreSQL 服务在跑（开机自启；没起就管理员运行 `net start postgresql-x64-17`）。
> 每步都标注了"你应该看到什么"——不对就停，先跑第 0 步自排查。

## 第 0 步 · 体检（1 分钟）

命令行：
```
python data/联调自检脚本.py
```
✅ 应看到：**16 项全部 [OK]**（契约/数据集/依赖/端口/数据库/工单联动证据）。有 NG 按提示修，别往下走。

## 第 1 步 · 基础版数据通道（2 分钟）

双击 **`data\WebSocket演示.bat`** → 浏览器测试页：
✅ 数值每 0.1 秒跳动、8 秒一轮；尖轨过 150 时整卡变红；曲线越过红色虚线。

进阶（全字段推送）：关掉 ws 黑窗口，命令行
```
cd data
python WebSocket推送服务.py --dataset 卡阻
```
刷新测试页 → ✅ 自动多出"全字段数据"面板（电流/功率/锁闭/密贴/振动/轨温 11 项实时跳）。
看完 `Ctrl+C` 关掉。

## 第 2 步 · 库内实时表（1 分钟）

双击 **`data\实时表格演示.bat`** → 弹出 psql 窗口：
✅ realtime_value 表每秒自动刷新，数值在跳。关掉两个窗口。

## 第 3 步 · 服务API主线（8 分钟，核心成果）

双击 **`data\服务API演示.bat`**（首次防火墙弹窗点"允许"）→ 浏览器状态板：

1. ✅ 绿色环形仪表：健康度 **100/优**；
2. 点 **卡阻** → 看三个联动：健康度跳水 **55/故障**（红环）、下方迷你曲线同步下坠、约 3 秒后"工况自动识别"报出 **卡阻 · 置信度99%**；
3. 滚到工单看板 → ✅ 多了"自动生成"工单 → 点 **维修闭环** → 系统自动重演正常转换复测 → 健康度自己回到 **100/优**、识别回到"正常转换"；
4. 再挨个点 **密贴不良**、**锁闭失败**，看识别和健康度的不同反应（75/良、65/预警）；
5. 点 **停止**。

## 第 4 步 · 历史趋势页（2 分钟）

状态板点"📈 趋势回放页"（或开 `http://localhost:8000/trend`）：
- ✅ 默认即**一天全景**：00:00~20:00、1700 点、12 个背景色段（四工况演示 + 一天 13 次运维动作）；
- "叠加"选 `T01-SM-01-CURR`（电流）→ 回放 → 看卡阻段：位移走平、电流爬升后归零；
- "时段"切"一天运维·卡阻"→ 单看 11 点那次故障。

## 第 5 步 · 诊断与系统状态页（1 分钟）

- `http://localhost:8000/api/diagnosis` → ✅ 浏览器版诊断页（健康度+识别+维修建议，3 秒自刷新）；
- `http://localhost:8000/api/stats` → ✅ 系统状态页（七表行数/延迟/触发器审计数/运行时长）。

## 第 6 步 · 数据库深处（3 分钟）

- pgAdmin 登录只读账号 **turnout_read / turnout_read**（库 turnout_twin）：
  ✅ Tables 7 张（多了 alarm_event/health_score/maintenance_log）、Views 4 个 `v_` 视图、表列有中文注释；
  双击 `v_source_stats` 看数据源统计一屏出。
- 或命令行体检：
```
python db/06_数据库体检.py
```
✅ 9 项全绿（含执行计划 0.1ms 走索引、缓存命中率 100%）。

## 第 7 步 · 验收级证据（可选，4 分钟）
