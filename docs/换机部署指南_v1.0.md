# 换机部署指南 v1.0（组长/A/C 在自己电脑上跑通全部内容）

> 目标：一台新电脑，从零到完整体验，约 **20 分钟**。
> 本机（B）已验证：全部脚本支持 PG* 环境变量覆盖数据库口令，pg_dump/psql 自动探测安装路径——
> **你的 PostgreSQL 密码不必和 B 相同**。

---

## 第 1 步 · 装两个软件（10 分钟）

1. **Python 3.10+**：https://www.python.org/downloads/ 下载后安装，**务必勾选 "Add Python to PATH"**（不勾会遇到"python 不是内部或外部命令"）。
2. **PostgreSQL 17**：https://www.postgresql.org/download/windows/ 下载安装。
   - 安装中会让你给 postgres 用户设密码——**设什么都行，记住它**（下面要用）；
   - 端口保持默认 5432；
   - 装完它会是 Windows 服务开机自启，不用手动开。

## 第 2 步 · 拿到项目 + 装依赖（3 分钟）

GitHub Desktop：File → Clone repository → 选 `VictoryLumos/new_turnout_digital_twin` → 本地随便哪个文件夹。
（或命令行 `git clone https://github.com/VictoryLumos/new_turnout_digital_twin.git`）

命令行进入项目文件夹，装 4 个包：

```
pip install websockets psycopg2-binary fastapi uvicorn
```

## 第 3 步 · 建库并恢复全部数据（3 分钟，一条命令）

**如果你的 postgres 密码不是 `postgres`**，先在 PowerShell 里设环境变量（本窗口内有效）：

```powershell
$env:PGPASSWORD = '你的密码'
```

然后执行两步：

```powershell
# 1) 建空库（psql 在 PATH；没有就去 C:\Program Files\PostgreSQL\17\bin\ 找）
psql -U postgres -c "CREATE DATABASE turnout_twin;"

# 2) 整库恢复（34000条数据+7张表+视图+触发器，一步到位）
psql -U postgres -d turnout_twin -f "data\导出数据\turnout_twin_整库备份_20260927.sql"
```

> 恢复时若看到几行 `role "turnout_read" does not exist` 警告——**忽略即可**（那只是只读账号的授权，
> 你机器上还没建这个角色，不影响任何数据）。想补建只读账号：`psql -U postgres -d turnout_twin -f "db\05_数据库升级v2.sql"`。

**不想用备份**也可以走脚本链（效果相同）：`01_建表与种子数据.sql` → `05_数据库升级v2.sql` →
`02_数据导入脚本.py` → `04_扩展数据入库.py` → `07_运维历史入库.py`。

## 常见问题

| 症状 | 处理 |
|---|---|
| python 不是内部或外部命令 | 重装 Python 勾选 Add to PATH，或用完整路径 |
| 数据库连不上/密码错 | 密码非 postgres 时：PowerShell 先 `$env:PGPASSWORD='你的密码'`；或服务没起：`net start postgresql-x64-17` |
| can't open file | 先 `cd` 进项目文件夹再执行命令 |
| 防火墙弹窗 | 服务API演示 首次启动会弹，点"允许访问"（局域网演示需要） |
| 恢复备份时报 turnout_read 不存在 | 忽略（无害），见第 3 步说明 |
