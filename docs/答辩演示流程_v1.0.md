# 道岔数字孪生答辩演示流程 v1.0（B线，2026-10-03）

> 按组长第三轮建议整理："先完成三项修复，再加告警记录和趋势图，最后整理一套答辩演示流程。"
> 全程约 **6 分钟**（可压缩到 3 分钟：跳过标 ⚡ 的步骤）。前置：PostgreSQL 服务运行中。

## 准备（演示前 2 分钟，双击即可）

| 步骤 | 操作 | 验证 |
|---|---|---|
| 1 | 双击 `data/服务API演示.bat` | 黑窗口出现 uvicorn running，浏览器开 http://localhost:8000 |
| 2 | 双击 `data/WebSocket演示.bat` | 黑窗口显示"[服务] 已启动 端口3003" |
| 3 | 打开 C 的 iTwin 页面（连 ws://B机IP:3003） | 页面"正在更新" |

讲解口径：**数据链路 = A仿真/模型 → B 管道（校验→入库→推送）→ C 页面（变红/恢复）**。

## 第一幕：数据服务与告警变化记录（约 1.5 分钟）

1. 打开首页 http://localhost:8000 —— 若未回放显示"**无数据**"（不虚报 100/优）；数据就绪后显示健康度。
2. 点「**告警演示**」工况注入 → 首页数值刷新；
3. 指「**告警变化记录**」区块逐条讲：*何时超限 → 哪个测点 → 峰值多少 → 何时恢复*
   （例：00:00:05.100 心轨超限 峰值112mm（阈值100）→ 00:00:09.500 恢复）——
   **比只看变红更容易验收**（组长第三轮页①原话）；
4. 工单看板：告警自动生成工单 → 点「维修闭环」→ 自动重演正常转换、健康度回升。

## 第二幕：五路位移趋势总览（约 1.5 分钟）

1. 打开 http://localhost:8000/trend5 —— 五条曲线：**尖轨三个牵引点（蓝色系）+ 心轨两个（黄色系）**；
2. 指图例讲模型对应：五个测点=**同一根尖轨的三个牵引点+同一根心轨的两个牵引点**
   （第二牵引点≠第二根钢轨——A 交付映射表已确认）；
3. 红色虚线=演示阈值（尖轨>150/心轨>100，**等于不告警，严格大于才告警**）；
   设计动程 160/118/75/100.6/55.5 是设计参数，不是故障限值；
4. 选 0.5× 或 0.25× **慢速回放**讲解转换过程；点暂停 → 页面明确显示
   "**⏸ 回放已暂停 · 当前值 …**"（组长第三轮页③）。

## 第三幕：iTwin 页面变红与恢复（约 1.5 分钟，验收核心）

> 口径=组长验收原文：**收到 B 的数据、两路分别超限变红、恢复后颜色还原、断线提示并自动重连。**

1. C 页面确认在收 B 的数据（time 为 UTC ISO 当前时间，每 0.1s 一帧）；
2. 推送 `工况_告警演示`：t≈2.1s **尖轨（SwitchRail）单独变红**（150.1>150）；
3. t≈5.1s **心轨（PointRail）也变红**（100.1>100）——两路分别判断；
4. t≈4.5s/7.0s 起先后**恢复颜色还原**；
5. ⚡ 断线演示：关掉 B 推送黑窗口 → 页面 5 秒后提示"数据未更新"并保留颜色；
   重开服务 → 页面 2 秒自动重连恢复刷新。

## 第四幕：数据可靠性（约 1 分钟，答"你们数据可信吗"）

1. **非法数据拒绝**：演示推送一个含 NaN 的文件 → 服务拒绝启动并定位"行2[字段]"；
   （或直接展示 docs/整改验证记录_第三轮_20261003.md §B 的 6 条记录）
2. **历史完整日期查询**：浏览器开
   `/api/history/T01-SR-01-DISP?start=2026-09-26T04:00:00+08:00&end=2026-09-26T04:00:12+08:00`
   —— 支持完整日期+时区，输出含时刻ISO；
3. ⚡ **断线恢复**：展示验证记录 §A——停机窗口内服务不退出，恢复后自愈且不重复写入；
4. ⚡ **同批次幂等**：同一批次重复导入不新增记录（验证记录 §C）。

## 常见提问与答点

| 可能提问 | 答点 |
|---|---|
| 数据是真的吗？ | 当前为仿真回放（dataSource=SIMULATED，消息里显式标注）；缺失三路按 A 确认的设计动程比例模拟并在 simFields 标注，不冒充实测 |
| 阈值哪来的？ | 演示阈值（150/100，严格大于），非工程故障限值；其余三点未配置，不得用设计动程代替 |
| 健康度怎么算的？ | 规则评分+稳态门（电机运行中只判过程类故障），无数据时显示"无数据"不虚报 |
| 数据库挂了怎么办？ | ResilientDB 自动重连重放（指数退避5次），停机恢复后自愈、不重复写入（验证记录§A实测） |
| 和模型怎么对应？ | 业务测点名（T18-…）与模型节点名（SwitchRail/PointRail）分列；本地 UserLabel/云端 NodeName 匹配，不混写 |
