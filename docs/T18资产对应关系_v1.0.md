**关键结论（对应组长命名红线）：**

1. 五个位移测点 = **两根钢轨**（尖轨 SwitchRail 一根、心轨 PointRail 一根）上的五个牵引点，
   不是五根钢轨；业务测点名（T18-…-DISP-n）与模型节点名（SwitchRail/PointRail）是两套体系。
2. 变红定位只认**模型节点名**：SwitchRail / PointRail（ECSQL UserLabel 匹配 →
   EmphasizeElements，接口契约原文）；SwitchRail_02、PointRail_02 不自动继承告警。
3. 资产ID 为项目内部编码（T18-VERIFIED…/T18-C6D192…），**不代表已在 AssetWise 登记**；
   sensorId/workOrderId 为 null（未配置真实传感器/工单关联）。
4. 理论转换力 837/699/2254/179/4529 N 是**静态设计参数**，不是遥测字段或实测力。
5. 设计动程（160/118/75/100.6/55.5）是设计参数，**不是故障限值**；演示阈值仅第 1 牵引点
   150/100 两处，其余三点未配置，不得用设计动程自动代替。
