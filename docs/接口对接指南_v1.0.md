# A / C 接口对接指南 v1.0（B 线数据服务）

> 给 A（模型/仿真）和 C（网页可视化）的**实操手册**：怎么拿数据、怎么推数据、怎么连数据库。
> 契约依据：《数据格式约定_v2.0_草案.md》；服务由 B 维护，启动方式：B 机双击 `data/服务API演示.bat`。
> 基址：本机 `http://localhost:8000`，跨机 `http://<B的IPv4>:8000`（B 机 `ipconfig` 查）。

## C（网页端）对接

### 1. 三条数据通道（任选，全部就绪）

**通道一：本地 JSON（默认，零依赖）**
```js
fetch('data/data.json').then(r => r.json()).then(rows => {
  // rows: [{time, switchRailDisp1, pointRailDisp1}, ...] 80条×0.1s
  // 位移毫米 × 0.001 = 米（Three.js 世界坐标）；尖轨>150 / 心轨>100 变红
});
```

**通道二：WebSocket 实时推送**（B 先启动推送服务）
```js
const ws = new WebSocket('ws://<B的IP>:8765');
ws.onmessage = e => { const d = JSON.parse(e.data); /* d 即一行数据对象 */ };
// 推送内容 = 数据文件行对象原样；B 可切 --dataset 卡阻 推20字段全量数据，
// 页面按需取字段、**忽略不认识的字段即可**（契约v2.0前向兼容规则）
```

**通道三：HTTP API（CORS 已全开，跨源直调不受限）**
```js
// 实时值（含告警标记）
const rt = await (await fetch('http://<B的IP>:8000/api/realtime')).json();
// 某测点历史（趋势图数据源）
const h = await (await fetch('http://<B的IP>:8000/api/history/T01-SR-01-DISP?limit=500')).json();
// 健康度/工单/识别（仪表盘卡片直接渲染）
const health = await (await fetch('http://<B的IP>:8000/api/health')).json();
const ident  = await (await fetch('http://<B的IP>:8000/api/identify')).json();  // 工况自动识别+置信度
```

### 2. 3D 模型节点映射（一条请求拿全）

```js
const m = await (await fetch('http://<B的IP>:8000/api/model')).json();
// m.构件: [{编码,类型,模型节点,资产ID,测点数}...]  → SwitchRail/PointRail/...
// m.测点映射: [{测点,数据字段,模型节点,单位,阈值,所属构件}...]
```
用法：数据字段值 → 按"测点映射"找到 glTF 节点名 → `毫米×0.001` 移动模型 → `value > 阈值` 变红。
**A 导出模型后若节点名有变，B 只改数据库，`/api/model` 实时返回新映射，C 不用改代码。**

### 3. 页面可以直接抄的参考实现

- `data/WebSocket测试页面.html`——WS 连接+超限变红+实时曲线，连接代码可整段复用；
- `http://<B的IP>:8000/trend`——canvas 画时序曲线（含阈值线/分段背景/回放光标）的实现；
- `http://<B的IP>:8000/`——健康度仪表/工单看板/识别卡片的轮询渲染。

## A（模型/仿真）对接

### 1. 交 CSV（约定流程）

```bash
python data/仿真数据转换脚本.py --file 你的UM数据.csv        # 自动校验列名/步长/数值
python data/仿真数据转换脚本.py --file xx.csv --step 0.01    # 步长不是0.1s时指定
```
- 必选列：`time / switchRailDisp1 / pointRailDisp1`；可选 17 列（电流/功率/锁闭/密贴/力/振动/磨耗/轮轨力/轨温等，列名对照契约 v2.0 第 2 节）有哪列带哪列；
- 列名不同只改脚本顶部 CONFIG 三行；未知列会列出来提醒（防拼写差异静默丢数据）；
- 转出的 JSON 替换 `data/data.json` 前群通知；入库 `python db/02_数据导入脚本.py --file xx.json --reset`。

### 2. 直推接口（不想走文件时）

```bash
curl -X POST http://localhost:8000/api/ingest -H "Content-Type: application/json" -d ^
 "{\"source\":\"um-batch1\",\"rows\":[{\"time\":0.0,\"switchRailDisp1\":0,\"pointRailDisp1\":0},{\"time\":0.1,\"switchRailDisp1\":12.3,\"pointRailDisp1\":0.5}]}"
```
- 字段按契约，未知字段忽略并回显；时间给 `time`（秒）或 `ts`（ISO8601）均可；
- 入库幂等（重复推自动跳过），触发器自动做超阈审计，实时值与健康度立即更新。

### 3. 模型节点名确认后

告诉 B 对应关系（或自己用 turnout_read 账号 UPDATE component.model_node），C 端 `/api/model` 自动生效。

## 常见问题

| 症状 | 原因/处理 |
|---|---|
| fetch 跨源报错 | 本服务已开 CORS；若还报错，检查是不是连错端口/服务没起 |
| 页面拿到未知字段害怕 | 契约规则：忽略即可，基础3字段永不变 |
| 想要实时推送全字段 | 让 B 用 `--dataset 工况` 启动推送服务 |
| 历史接口 404 | 测点编码写错，先 `/api/points` 查编码 |
| ingest 返回 400 | rows 里没有契约字段；看响应里"收到的键"提示对照改字段名 |
