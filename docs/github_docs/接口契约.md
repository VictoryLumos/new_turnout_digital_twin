# 接口契约

适用版本：18号道岔 V2.1 本地 iTwin.js 演示，2026-09-27。
当前未接入真实传感器，所有实时数据来自模拟回放。以下是现有程序实际行为，不是生产传感器协议。

## 数据传输

- 本地服务：http://127.0.0.1:3002 。WebSocket：ws://127.0.0.1:3002/telemetry；若以HTTPS部署，前端使用同域wss。
- 服务端每1.5秒发送一个JSON对象，循环播放data.json，并替换time为本次发送时间。此时间不是实际传感器采集时间。
- time及以下五个动程字段均必填，每帧为完整快照，不是增量更新。
- time：字符串，发送格式为UTC ISO 8601，例如2026-09-27T08:00:00.000Z；接收端要求能被Date.parse解析。
- 五个动程字段：有限JSON数值，单位均为毫米。拒绝缺失、null、字符串、NaN或Infinity；当前未实施物理量程校验。
- dataSource：当前发送值SIMULATED，为附加说明字段；现有解析器不将其作为必填字段，也不校验其取值。未知字段不参与告警。

## 字段、构件与阈值

|字段|单位|关联模型节点|设计动程|演示告警条件|关联示意设备|
|---|---|---|---:|---|---|
|switchRailDisp1|mm|SwitchRail|160|> 150 mm|SwitchMachine|
|switchRailDisp2|mm|SwitchRail|118|未配置|SwitchMachine_02|
|switchRailDisp3|mm|SwitchRail|75|未配置|SwitchMachine_03|
|pointRailDisp1|mm|PointRail|100.6|> 100 mm|PointMachine|
|pointRailDisp2|mm|PointRail|55.5|未配置|PointMachine_02|

阈值为严格大于：150/100本身不触发，150.1/100.1触发。尖轨与心轨分别判断、分别变红；恢复到阈值以内时清除对应主节点颜色。其他三测点没有告警阈值，不能用设计动程自动代替。

SwitchRail、PointRail通过ECSQL的UserLabel匹配获取元素ID，使用EmphasizeElements标红；不使用GLB节点索引作为iModel元素ID。SwitchRail_02、PointRail_02不自动继承上述告警。

设计动程是设计参数，不是工程故障限值。红色仅代表演示规则触发。五点理论转换力837/699/2254/179/4529 N属于静态参数，不是遥测字段或实测力。

## 时间有效性与断线

- 时间戳不大于上次已接收有效时间戳的帧被忽略。
- 与浏览器当前时间差绝对值大于10秒的帧不接受。两端时钟需要一致。
- 超过5秒未收到新的有效帧，标记数据未更新；保留上次数值及颜色，不视为恢复正常。
- 连接关闭后约2秒重试。连接成功不代表数据恢复，须收到新的有效帧才显示正在更新。
- 非法数据不覆盖上次有效结果。前端没有向真实设备下发控制命令。

## 报文示例

```json
{
  "time": "2026-09-27T08:00:00.000Z",
  "switchRailDisp1": 160,
  "switchRailDisp2": 118,
  "switchRailDisp3": 75,
  "pointRailDisp1": 100.6,
  "pointRailDisp2": 55.5,
  "dataSource": "SIMULATED"
}
```

示例time为说明用途；实际发送时必须生成当前时间，否则会被判为过期。

## 只读HTTP接口及映射

|路径|内容|
|---|---|
|GET /api/model|本地快照key、viewId、elementCount、modelVersion、mode|
|GET /api/design|五牵引点设计参数及模拟/未连接状态|
|GET /api/mapping|当前本地iModel的节点名、资产与elementId等运行时映射|

同目录《编码与映射表.json》是原mapping.json的逐字节副本，含2902构件及5个测点的静态编码关系。它与/api/mapping的运行时iModel映射结构不同，不应互换。
sensorId、workOrderId为null，表示尚未配置；现有assetId是项目内部编码，未表示已在AssetWise登记。iModel重新生成后应重新查询elementId。
